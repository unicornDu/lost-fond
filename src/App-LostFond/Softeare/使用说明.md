# 拾光 · Windows 桌面版 使用说明

版本：**Windows 1.1.2**（2026-10-22，原生登录窗口 1042×673 + Glow 图标 + 自选安装位置）
适用文件：

| 文件 | 平台 | 大小 |
|---|---|---|
| `Shiguang-Windows-Setup-1.1.2.exe` | Windows 10 / 11（64 位） | 约 162 MB |

> 安装包**内置后端、Java 运行环境和 H2 数据库**，安装后双击即用，不需要再装 MySQL / JDK，也不需要云服务器。
> 每个用户的数据保存在自己电脑的 `%APPDATA%\Shiguang` 中。
>
> 从 GitHub 获取时，请在仓库的 [Releases](https://github.com/unicornDu/lost-fond/releases) 页面下载安装包；下载后可与 `SHA256SUMS.txt` 放在同一目录做校验。

## 一、安装

1. 双击 `Shiguang-Windows-Setup-1.1.2.exe`。
2. 如果出现蓝色提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**（安装包未做商业代码签名，属正常现象）。
3. 进入安装向导：
   - **安装选项**：选择「仅为我安装」（默认，不需要管理员权限）或「为使用这台电脑的任何人安装」。
   - **选择安装位置**：默认是 `%LOCALAPPDATA%\Programs\shiguang-desktop`；点 **浏览(B)...** 可以安装到其他文件夹（例如 `D:\Apps\Shiguang`）。
   - 点 **安装(I)** 开始安装；完成后桌面和开始菜单会出现「拾光」快捷方式，并自动启动。
4. 建议安装到**纯英文、非受保护**的目录。未签名程序放在中文路径或被联想电脑管家/火绒等安全软件保护的文件夹里，可能被拦截，表现为双击没反应。

> **之前装过 1.0.0 的用户**：旧版可能被装在受保护目录（例如 `D:\新建文件夹\...`），里面的程序会被安全软件拦截。请使用 1.1.2 安装后生成的新快捷方式；旧版可在「设置 → 应用」中卸载（需管理员），不影响已有数据。
>
> **已装 1.0.1～1.1.1 的用户**：直接运行 1.1.2 安装包覆盖安装即可，`%APPDATA%\Shiguang` 中的数据和演示账号保持不变。1.1.2 包含原生登录窗口、无边框标题栏和自选安装位置，登录窗口为 Qoder 同尺寸（1042×673），图标更换为白底 Glow 笑眼。

## 二、首次启动与登录

1. 双击桌面「拾光」，先出现**独立的登录窗口**（不是浏览器页面），窗口会显示本地服务启动进度。
2. 等状态变为 **本地服务已就绪**，点 **立即登录**，输入学号与密码。
3. 勾选「记住登录状态」后，下次启动会自动进入主界面；不勾选则每次都需要登录。
4. 登录成功后进入主窗口。主窗口顶部是自绘标题栏，左侧是「拾光」品牌，右侧是窗口控制按钮；原来的系统菜单栏已移除，服务信息、数据目录、退出登录等入口在标题栏的 **应用** 菜单里。
5. 首次启动 Windows 可能弹出防火墙提示：勾选 **专用网络**，点 **允许访问**。
6. 菜单栏 **应用 → 服务信息 / 局域网地址** 可随时查看：
   - 本机地址：`http://127.0.0.1:18080/`
   - 局域网地址：`http://192.168.x.x:18080`
   - 演示账号、数据目录、日志路径
7. 不要把安装后的程序目录移动到中文或受安全软件保护的文件夹；需要迁移时请重新运行安装包。

### 局域网访问（可选）

同一 Wi-Fi 下的其他电脑或手机，可以直接用浏览器打开「服务信息」里的局域网地址，访问同一份数据，无需安装任何客户端。电脑端退出后，该地址不可用。

## 四、数据与卸载

- 数据库与上传图片：`%APPDATA%\Shiguang\data`
- 运行日志：`%APPDATA%\Shiguang\logs`
- 登录状态：`%APPDATA%\Shiguang\session.bin`（使用 Windows 系统加密；删除后下次启动需重新登录）
- **重置演示数据**：退出「拾光」，删除 `%APPDATA%\Shiguang\data` 文件夹，再启动即可重新播种。
- 卸载：Windows「设置 → 应用 → 已安装的应用 → 拾光 1.1.2 → 卸载」。当前用户安装无需管理员；卸载**不会**删除上面的数据目录，需要时手动删除。
- 若列表里同时存在「拾光 1.0.0」，那是之前安装到受保护目录的旧版，可一并卸载。

## 五、常见问题

### 1. 双击没反应

| 现象 | 处理 |
|---|---|
| 双击桌面「拾光」没有窗口 | 右键快捷方式 → 属性 → 目标，确认指向实际安装目录下的 `shiguang.exe`。若仍指向 `D:\新建文件夹\...`，说明点的是旧版快捷方式，请使用 1.1.2 安装后生成的新快捷方式。 |
| 新版也打不开 | 直接到安装目录双击 `shiguang.exe`；仍无反应时查看 `%APPDATA%\Shiguang\logs\backend.log`，或关闭联想电脑管家/火绒的文件夹保护后重试。 |
| 提示端口占用 | 关闭已运行的「拾光」后重试；程序会自动改用 18080–18099 的空闲端口。 |
| 想换安装位置 | 重新运行 1.1.2 安装包，在「选择安装位置」页点「浏览」；覆盖安装不会删除 `%APPDATA%\Shiguang` 数据。 |

### 2. 登录窗口相关

| 现象 | 处理 |
|---|---|
| 状态一直停在「正在启动本地服务…」 | 首次启动建库约需 5～15 秒；超过 1 分钟仍无变化时查看 `%APPDATA%\Shiguang\logs\backend.log`，并确认安全软件没有拦截内置 `java.exe`。 |
| 提示学号或密码错误 | 检查大小写与数字；连续输错会临时锁定 10 分钟。演示账号见上方表格。 |
| 忘记密码 | 当前版本不提供自助重置，请联系管理员在后台重置密码。 |
| 想退出登录 | 主窗口标题栏 **应用 → 退出登录**，会回到原生登录窗口；也可以直接关闭窗口后重新启动。 |
| 下次启动不想自动登录 | 登录时取消勾选「记住登录状态」；已勾选的可先「退出登录」，再取消勾选登录。 |

### 3. 局域网地址打不开

| 现象 | 处理 |
|---|---|
| 其他设备打不开 | 确认电脑端「拾光」仍在运行，地址、端口是否抄对（默认 18080） |
| 电脑本机能开、其他设备不行 | Windows 防火墙未放行：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙，找到 `java.exe` 勾选「专用」；或临时关闭防火墙测试 |
| 同一 Wi-Fi 仍不通 | 路由器开启了「AP 隔离 / 访客网络」，换到主网络再试 |
| 电脑换了网络后连不上 | 局域网 IP 会变，重新看「应用 → 服务信息」里的新地址 |

## 六、说明与限制

- 安装包为课程演示用途，**未做商业代码签名**：Windows SmartScreen 可能提示风险，选择继续安装即可。
- 安装位置可以自定义；但不要把程序放到中文路径或被安全软件保护的目录，否则未签名程序可能被拦截。
- Windows 版同一时间只允许运行一个实例；重复双击会聚焦已打开的窗口，不会重复启动服务。
- 每个用户安装后拥有独立的本地数据，不会自动与其他电脑同步；需要多人共用数据时，使用同一台电脑的局域网地址访问。
- 登录页右侧插画当前为占位图，源码中可通过替换 `App-LostFond/desktop/login/login-art.svg` 更换。
- 本项目 Web 版（`web-lostfond`）保持原样，未做任何改动；桌面版源码在 `App-LostFond` 中独立维护。
