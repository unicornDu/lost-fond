# other/ 目录说明（其他资料）

> 本目录是提交包四目录结构中的 `other/`，存放文档、模型、源码之外的其他资料。
> 给评审老师的一句话：**本目录 = 软件安装说明书 + 宣传材料 + 运行辅助工具 + 项目构建过程资料**。前三样是课程要求的提交物，最后一样是我们做这个项目的完整过程留痕，供了解开发方式与迭代轨迹，不属于交付文档本体（交付文档在 `doc/`）。

## 目录内容

| 子项 | 类型 | 说明 |
|---|---|---|
| `软件安装说明书-v1.0.md` | 安装说明书 | 从零安装运行的完整步骤（环境→建库→配置→启动→验收→排错）。**提交前转换为 Word（.docx）后连同本 md 一并保留**（老师要求 Word 版） |
| `宣传彩页/宣传彩页.html` | 宣传彩页 | A4 单页彩页。用浏览器打开 → `Ctrl+P` → 目标选"另存为 PDF"即可导出成品 |
| `演示视频/` | 演示视频 | **待补**：录制后放 `演示视频-第x组.mp4`（命名与录制大纲见目录内 README） |

| `Creator/` | 构建过程资料 | 见下方专节 |

这是本小组**从选题到交付的完整过程留痕**（我们把它一并提交，是为了向老师展示项目是如何一步步做出来的；过程文档与正式交付文档分离，正式交付物在 `doc/`）：

| 子目录 | 内容 |
|---|---|
| `过程资料/选题/` | 选题论证、GitHub 同类项目调研（2026-09-28）、五人分工方案、项目准备清单 |
| `过程资料/设计prompt/` | 页面设计 prompt（含已归档的多端方案） |

| `过程资料/参考项目/` | 调研阶段下载的三个上游开源项目离线副本（见下方声明） |
| `Knowledge_List/` | 答辩复习知识清单（8 份 · 208 个自测点） |
| `CONTRIBUTING.md` | 小组 git 协作规范与提交前检查单 |

### 参考项目声明（重要）

`Creator/过程资料/参考项目/` 内的三个项目（314loveshiwu、JImageHash、vue-element-admin）是**选题调研阶段下载的他人开源项目副本**，仅用于学习架构、表设计与页面布局，**不是本小组的交付代码**；本项目全部交付代码在 `src/`，二者无代码包含关系。调研结论（"市面同类项目均为文字搜索，无以图搜图"）记录在 `Creator/过程资料/选题/失物招领-参考项目与前端模板.md`。
