## 1. Vue 3 基础

- [ ] **组合式 API vs 选项式**：组合式（`<script setup>`）按"逻辑"组织代码，相关变量/函数放一起；选项式按 `data/methods/computed` 分块，逻辑被切碎
- [ ] `ref(x)`：包装基本类型成响应式，**脚本里改要 `.value`，模板里直接用**
- [ ] `reactive(obj)`：对象版响应式，直接改属性
- [ ] `computed(fn)`：派生值，依赖变化自动重算，**有缓存**
- [ ] `watch(src, cb)`：副作用（如筛选条件变了重新请求）
- [ ] `onMounted(fn)`：组件挂载后执行（本项目首次请求基本都放这里）
- [ ] `onUnmounted`：清理定时器/监听（**AppSidebar 的 30s 未读轮询必须清，否则路由切换后仍在跑**）

**追问**：`computed` 和 `watch` 怎么选？→ 要"一个值"用 computed；要"做一件事"（请求、弹窗、存缓存）用 watch。

- [ ] 能解释"为什么 `ref` 要 `.value` 而 `reactive` 不用"（ref 返回的是包装对象，靠 getter/setter 拦截）

## 2. SFC 与模板

- [ ] 一个 `.vue` = `<script setup>`（逻辑）+ `<template>`（结构）+ `<style scoped>`（样式）
- [ ] `scoped` 的作用：给元素加唯一属性选择器，样式只作用于本组件（避免全局污染）
- [ ] 模板指令：`v-if/v-else`、`v-for`、`v-model`、`@click`、`:src`、`:class`、`{{ }}`
- [ ] **`v-if` vs `v-show`**：`v-if` 真销毁/重建（切换成本高、初始不渲染）；`v-show` 只是 `display:none`（切换便宜）。频繁切换用 `v-show`
- [ ] `v-for` 必须给 `:key`，用**业务唯一 id**，不要用 index（列表增删会错位）

- [ ] 被问"v-for 为什么不用 index 做 key"时能举反例（删除中间项导致状态错位/复用错误 DOM）

## 4. 路由（★必会）

- [ ] 路由表：`/`落地、`/auth`登录、`/home`、`/wall`、`/publish`、`/item/:id`、`/search-image`、`/profile`、`/user/:id`、`/admin/*`、`/:pathMatch(.*)*` 404 兜底
- [ ] 动态参数：`/item/:id` → `useRoute().params.id`
- [ ] 路由懒加载：`component: () => import('...')` → 按需分包，首屏更快
- [ ] `meta`：`meta.public`（公开页）、`meta.roles:['admin']`（管理员页）、`meta.title`（浏览器标题）

### 4.1 路由守卫三层逻辑（能背）

```js
router.beforeEach((to) => {
  // ① 非公开页且未登录 → 去登录，并记住来源（登录后回跳）
  // ② 已登录还去 /auth → 回首页
  // ③ 非管理员进 /admin/* → 回首页
})
router.afterEach((to) => { document.title = to.meta.title })  // ④ 设置标题
```

- [ ] 能说出四条规则
- [ ] 能解释"为什么前端守卫不算安全措施"（可被绕过，真正校验在后端）

### 4.2 history vs hash 路由

| 模式 | URL | 需要服务端配合 | 本项目用在哪 |
|---|---|---|---|
| history | `/wall` | **需要**（刷新/直链要回退到 index.html） | Web（后端有 SPA 回退） |
| hash | `/#/wall` | 不需要 | （本项目不用；单 Web 一律 history） |

- [ ] 能解释"为什么 `file://` 下必须用 hash"（没有 HTTP 服务器，history 路由刷新会找不到文件）

## 10. 构建与性能

- [ ] Vite：开发用 ESM 原生模块（启动快）、生产用 Rollup 打包
- [ ] `manualChunks` 分包：`element-plus` 单 chunk、`echarts` 独立、其余 vendor
- [ ] **★踩过的坑（F-11）**：把 Element Plus **按组件首字母拆成多个 chunk** → 组件间双向依赖跨 chunk 成环 → 生产构建报 `Cannot access 'xx' before initialization`（TDZ）→ Vue 未挂载 → **页面只剩背景色白屏**
- [ ] 教训：**dev 正常 ≠ build 正常**；改打包配置后必须 `npm run build` 并用浏览器控制台验收
- [ ] 其他优化：路由懒加载、缩略图（480px）、列表分页上限 100
