# 软件工程课程设计 · 选题推荐（V2：纯 Java 技术栈，不依赖 Python）

> 技术基线：Java、JavaWeb（Spring Boot / SSM）、C；前端 Vue 或微信小程序
> **本版原则：后端全部用 Spring Boot；"AI 功能"一律通过云服务 API 的 Java SDK / HTTP 接口实现（百度 OCR、讯飞语音、大模型 API 均有官方 Java SDK 和免费额度），算法部分用纯 Java 可实现，小组不需要写 Python。**
> 小组分工：项目经理 / 分析设计及文档 / 编码及文档 / 测试及文档 / 数据库及文档 / 美工

---

## 一、推荐选题清单（8 个，按推荐顺序）

### 1. 基于微信小程序的校园二手交易平台的设计与实现 ⭐最稳妥，首推
- **做什么**：发布/搜索/收藏/下单/站内聊天/评价的校园二手交易闭环；加分点：接百度内容审核 API 自动拦截违禁品图片（Java SDK 调用即可）。
- **新颖点**：业务经典但流程最完整，加图像审核后脱离"烂大街管理系统"。
- **技术栈**：Spring Boot + MySQL + Redis + 微信小程序（或 Vue）。
- **难度**：★★（全部是课堂学过的东西，最容易按时交付）
- **参考项目**：
  - litemall：Spring Boot + Vue + 小程序完整商城（约 19k star）：https://github.com/linlinjava/litemall
  - newbee-mall：结构简单的学习型商城（约 13k star）：https://github.com/newbee-ltd/newbee-mall
  - mall：数据库/表设计参考（约 80k star）：https://github.com/macrozheng/mall

### 2. 基于感知哈希的校园失物招领平台的设计与实现 ⭐新颖度与可行性平衡最好
- **做什么**：失物/招领发布 + 关键词匹配；核心亮点是"以图搜图"——上传失物照片自动匹配相似的历史图片（用感知哈希 pHash，纯 Java 算法，几十行代码）。
- **新颖点**：pHash 是纯 Java 就能实现的图像相似度算法，效果直观（拍一张水杯能匹配出之前登记的同款水杯），答辩演示惊艳且零 Python 依赖。
- **技术栈**：Spring Boot + MySQL + Vue/小程序 + JImageHash（纯 Java 感知哈希库）。
- **难度**：★★★
- **参考项目**：
  - JImageHash：纯 Java 感知哈希库：https://github.com/KilianB/JImageHash
  - 页面架构参考 litemall / vue-element-admin：https://github.com/PanJiaChen/vue-element-admin

### 3. 基于 OCR 云服务的智能错题本系统的设计与实现
- **做什么**：手机拍照 → 调百度 OCR API（Java SDK，有免费额度）识别题目 → 按科目/章节/知识点归类入库 → 接大模型 API 生成错题讲解和相似题 → 错题本导出 PDF 复习。
- **新颖点**：AI + 教育热点；"AI 部分"只是两个 API 调用，Java 一把梭；组员自己就是用户，需求分析好写。
- **技术栈**：Spring Boot + MySQL + Vue/小程序 + 百度 OCR Java SDK + 大模型 API。
- **难度**：★★★
- **参考**：百度智能云 OCR Java SDK 官方文档（免费额度每月 1000 次左右，课程够用）；大模型用 DeepSeek/智谱 API（免费额度）。

### 4. 基于协同过滤的校园活动报名与推荐平台的设计与实现
- **做什么**：社团活动发布/报名/签到平台 + 个性化推荐；推荐算法用 Java 手写"基于用户的协同过滤"（本质是对评分表做相似度计算，200 行以内纯 Java，正好让"数据库及文档人员"深度参与）。
- **新颖点**：替代老师清单里的"电影推荐系统"避免全年级撞题；数据自造自控，冷启动（问卷兴趣标签）+ 热度兜底等工程设计有话可写。
- **技术栈**：Spring Boot + MySQL + Vue。
- **难度**：★★
- **参考项目**：
  - MovieLens 数据集（可导入当测试数据）：https://grouplens.org/datasets/movielens/
  - 协同过滤原理任意搜"UserCF java 实现"，属于教科书算法，无框架依赖。

### 5. 基于语音识别云服务的课堂录音纪要助手的设计与实现
- **做什么**：课堂/会议录音上传 → 讯飞语音转写 API（Java SDK，免费额度）转文字 → 大模型 API 生成摘要、提取待办和关键知识点 → 纪要管理与检索。
- **新颖点**：语音 AI 应用赛道，但实现层面只是两个 API 调用 + 一个管理后台。
- **技术栈**：Spring Boot + MySQL + Vue + 讯飞 SDK + 大模型 API。
- **难度**：★★★

### 6. 基于大模型 API 的校园办事指南智能问答平台的设计与实现
- **做什么**：整理教务规章、奖助学金、选课、报修流程等常见问答入库，用户提问时系统先做关键词/分类检索（MySQL 全文检索即可），把命中的资料连同问题一起发给大模型 API 生成回答；附管理后台维护知识条目。
- **新颖点**：这是 RAG 的"学生版"——不用向量库和 Python，用数据库检索 + 大模型 API 就能达到 80% 效果，论文里还能讲清取舍。
- **技术栈**：Spring Boot + MySQL + Vue/小程序 + 大模型 API。
- **难度**：★★

### 7. 基于状态机流转的校园报修工单管理系统的设计与实现 ⭐保底题
- **做什么**：学生提交报修（图文）→ 派单 → 维修员接单处理 → 完工拍照 → 学生评价 → 超时自动催办/升级；后台统计各楼宇报修热力。
- **新颖点**：工单状态流转是软工课最爱考的场景——状态图、时序图、测试用例全都能画满写满，文档分稳。
- **技术栈**：Spring Boot + MySQL + Vue/小程序。
- **难度**：★★
- **参考项目**：
  - RuoYi-Vue 后台管理脚手架（约 40k star，仅作学习参考，注意别整包上交）：https://github.com/yangzongzhuan/RuoYi-Vue

### 8. 基于情感分析的 AI 心理树洞小程序的设计与实现
- **做什么**：匿名倾诉 + 情绪识别（大模型 API 打情绪标签，无需 Python 库）+ 情绪曲线记录 + 危机关键词自动提示学校心理中心热线 + 心理文章推送。
- **新颖点**：对应老师清单"医疗保健 App"方向；注意界面注明"仅作情绪陪伴，不构成诊疗建议"。
- **技术栈**：Spring Boot + MySQL + 微信小程序 + 大模型 API。
- **难度**：★★

## 三、Top 3 建议

1. **首推（稳 + 亮点兼备）：选题 2 失物招领平台** —— 主体是标准 JavaWeb 三层架构（大家都写过），pHash 以图搜图是纯 Java 几十行代码的"科技与狠活"，演示效果好、新颖度够、又不依赖任何没学过的技术。
2. **求最稳：选题 1 校园二手交易平台** —— 全部课堂知识，litemall/newbee-mall 参考成熟，业务流程完整，用例图、E-R 图、测试用例最好写。
3. **想沾 AI 光：选题 3 智能错题本 或 选题 6 办事指南问答** —— "AI"全部是云 API 调用（Java SDK 十几行代码），答辩时是加分项，实现上不构成风险。

## 四、注意事项

- 软件工程课评的是**过程与文档**（需求规格说明书、UML 建模、设计说明、测试报告、项目计划），代码只是载体 —— 工单、交易、报名这类流程完整的题最容易拿文档分。
- 云 API 都用免费额度：百度 OCR（每月约 1000 次免费）、讯飞语音（注册送额度）、DeepSeek/智谱大模型（注册送额度），课程作业完全够用；记得在报告里写清"调用第三方服务"。
- 参考项目用于学习架构，不要整包上交（尤其 RuoYi 脚手架），答辩会追问代码细节。
- 9 月 25 日前把分组编号、名单（学号、姓名）和选题 Excel 交班长/课代表。
