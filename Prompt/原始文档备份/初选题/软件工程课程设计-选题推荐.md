### 二、推荐排序（v2）

**首选 ①：基于协同过滤与深度学习的电影推荐系统 —— 全 Java 闭环，契合度第一**
- 语言映射：系统主体 Spring Boot + MyBatis + MySQL（JavaWeb 本栈）；协同过滤纯 Java 实现；"深度学习"部分二选一，都在栈内：
  - 路线 A：DL4J（Java 深度学习库，14257★，2026-09 仍更新）搭 NeuralCF/MLP，官方示例库 deeplearning4j-examples（2505★）可直接改；
  - 路线 B：用 Java 或 C++ 手写反向传播的小神经网络（几百行），论文里写"自实现深度模型"，反而是答辩新颖点，C/C++ 功底正好用上。
- 新颖点：混合推荐（CF + 深度模型）、推荐解释、冷启动策略、偏好标签可视化。
- 数据：MovieLens 公开数据集，导入 MySQL 即可。
- 风险：DL4J 依赖较多（Maven 拉包需联网）；路线 B 几乎零依赖更稳。

**求稳 ②：个性化博客平台设计与实现 —— 纯 JavaWeb，零新语言**
- 语言映射：100% JavaWeb + MySQL。
- 新颖点：个性化推荐流（直接复用 ① 的 Java 协同过滤代码）、AI 摘要/自动打标签（Java 发 HTTP 请求调大模型 API，不需要 Python）、个性化主题。
- 可选 C++ 亮点：JNI 调 C++ 写的倒排索引/敏感词过滤模块作性能卖点（不做也不影响成立）。
- 风险：题目本身不新，靠增量功能撑新颖度。

**移动端 ③：基于 Android 平台的新闻资讯 App —— Android 主语言就是 Java**
- 语言映射：Android 端 Java（零语言门槛，只需学 Android SDK，约 1-2 周）+ JavaWeb 后端 API + MySQL。
- 新颖点：新闻个性化推荐（内容相似度 + 协同过滤）、离线缓存、阅读统计大屏。
- 风险：需搭 Android 环境（Windows 上可行）、真机/模拟器调试耗时。

**C/C++ 主打 ④：基于 YOLO 的目标检测与计数系统 —— C++ 推理路线**
- 语言映射：C++ 推理服务（ONNX Runtime + OpenCV，直接加载社区现成的 yolov8n.onnx，不需要自己训练/导出）+ JavaWeb 管理端（视频/设备管理、计数报表、告警大屏）。
- 场景新颖点：课堂人数清点 / 校园路口车流 / 食堂排队监测，选一个讲故事。
- 风险：Windows 下 OpenCV C++ 环境配置（建议用仓库自带预编译库或 vcpkg）；答辩用录播视频兜底实时性。

**极限保底 ⑤：基于 C# 的建材类仓储账务一体化系统**
- 仅当全组想躺平选管理系统的场合：C# 与 C++/Java 同语法族，WinForms + MySQL 上手约一周，教程海量；但新颖度最低，且要新学一门语言，故排最后。

### 四、首选题 ① 的分工建议（5 人，对应课件角色）

1. 项目经理：里程碑计划、需求评审、答辩统筹。
2. 分析和设计及文档：需求规格说明、用例图/类图/时序图、接口文档。
3. 编码 A（JavaWeb）：用户/影片/评分/交互业务模块（Spring Boot + MyBatis）。
4. 编码 B（算法）：Java 协同过滤 + DL4J 或自实现神经网络模块（C/C++ 功底用在这里）。
5. 测试 + 数据库：JUnit 用例与测试报告；MySQL 建表、MovieLens 导入、ER 图。
（4 人时：数据库并入编码 A，测试独立。）

### 五、决策建议

- 想"新颖 + 稳"双收：投 ①；组内有人抗拒算法：退 ②；有人想做 App：选 ③；想秀 C++：选 ④。
- 定题后第一步：fork 基座仓库 → 本地跑通 → 再写需求文档，避免 9/25 交表后返工。
