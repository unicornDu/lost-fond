# 拾光 · Windows 桌面版 使用说明

版本：**Windows 1.0.2**（2026-10-22）
适用文件：

| 文件 | 平台 | 大小 |
|---|---|---|
| `Shiguang-Windows-Setup-1.0.2.exe` | Windows 10 / 11（64 位） | 约 162 MB |

> 安装包**内置后端、Java 运行环境和 H2 数据库**，安装后双击即用，不需要再装 MySQL / JDK，也不需要云服务器。
> 每个用户的数据保存在自己电脑的 `%APPDATA%\Shiguang` 中。
>
> 从 GitHub 获取时，请在仓库的 [Releases](https://github.com/unicornDu/lost-fond/releases) 页面下载安装包；下载后可与 `SHA256SUMS.txt` 放在同一目录做校验。

---

## 一、安装

1. 双击 `Shiguang-Windows-Setup-1.0.2.exe`。
2. 如果出现蓝色提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**（安装包未做商业代码签名，属正常现象）。
3. 本版为**一键安装**：不需要选择安装位置、不需要管理员权限，自动安装到当前用户目录：
   `%LOCALAPPDATA%\Programs\shiguang-desktop`
   安装完成后桌面和开始菜单会出现「拾光」快捷方式，并自动启动。

> **之前装过 1.0.0 的用户**：旧版可能被装在受保护目录（例如 `D:\新建文件夹\...`），里面的程序会被联想电脑管家/火绒拦截，表现为双击没反应。请使用本版新生成的桌面快捷方式；旧版可在「设置 → 应用」中卸载（需管理员），不影响已有数据。
>
> **已装 1.0.1 的用户**：直接运行 1.0.2 安装包覆盖安装即可，`%APPDATA%\Shiguang` 中的数据和演示账号保持不变。1.0.2 只是移除手机端相关代码与菜单措辞。

---

## 二、首次启动

1. 双击桌面「拾光」，先出现启动画面，约 **5～15 秒**完成建库和演示数据播种。
2. 首次启动 Windows 可能弹出防火墙提示：勾选 **专用网络**，点 **允许访问**。
3. 进入首页即表示启动成功。菜单栏 **应用 → 服务信息** 可随时查看：
   - 本机地址：`http://127.0.0.1:18080/`
   - 局域网地址：`http://192.168.x.x:18080`
   - 演示账号、数据目录、日志路径
4. 不要把安装后的程序目录移动到中文或受安全软件保护的文件夹，否则可能被拦截；需要迁移时请重新运行安装包。

### 局域网访问（可选）

同一 Wi-Fi 下的其他电脑或手机，可以直接用浏览器打开「服务信息」里的局域网地址，访问同一份数据，无需安装任何客户端。电脑端退出后，该地址不可用。

## 四、数据与卸载

- 数据库与上传图片：`%APPDATA%\Shiguang\data`
- 运行日志：`%APPDATA%\Shiguang\logs`
- **重置演示数据**：退出「拾光」，删除 `%APPDATA%\Shiguang\data` 文件夹，再启动即可重新播种。
- 卸载：Windows「设置 → 应用 → 已安装的应用 → 拾光 1.0.2 → 卸载」。当前用户安装无需管理员；卸载**不会**删除上面的数据目录，需要时手动删除。
- 若列表里同时存在「拾光 1.0.0」，那是之前安装到受保护目录的旧版，可一并卸载。

## 五、常见问题

### 1. 双击没反应

| 现象 | 处理 |
|---|---|
| 双击桌面「拾光」没有窗口 | 确认快捷方式指向 `%LOCALAPPDATA%\Programs\shiguang-desktop\shiguang.exe`（右键 → 属性 → 目标）。若仍指向 `D:\新建文件夹\...`，说明点的是旧版快捷方式，请使用 1.0.2 安装后生成的新快捷方式。 |
| 新版也打不开 | 直接到 `%LOCALAPPDATA%\Programs\shiguang-desktop` 双击 `shiguang.exe`；仍无反应时查看 `%APPDATA%\Shiguang\logs\backend.log`，或关闭联想电脑管家/火绒的文件夹保护后重试。 |
| 提示端口占用 | 关闭已运行的「拾光」后重试；程序会自动改用 18080–18099 的空闲端口。 |

### 2. 局域网地址打不开

| 现象 | 处理 |
|---|---|
| 其他设备打不开 | 确认电脑端「拾光」仍在运行，地址、端口是否抄对（默认 18080） |
| 电脑本机能开、其他设备不行 | Windows 防火墙未放行：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙，找到 `java.exe` 勾选「专用」；或临时关闭防火墙测试 |
| 同一 Wi-Fi 仍不通 | 路由器开启了「AP 隔离 / 访客网络」，换到主网络再试 |
| 电脑换了网络后连不上 | 局域网 IP 会变，重新看「服务信息」里的新地址 |

## 六、说明与限制

- 安装包为课程演示用途，**未做商业代码签名**：Windows SmartScreen 可能提示风险，选择继续安装即可。
- Windows 版同一时间只允许运行一个实例；重复双击会聚焦已打开的窗口，不会重复启动服务。
- 每个用户安装后拥有独立的本地数据，不会自动与其他电脑同步；需要多人共用数据时，使用同一台电脑的局域网地址访问。
- 本项目 Web 版（`web-lostfond`）保持原样，未做任何改动；桌面版源码在 `App-LostFond` 中独立维护。
