## 移动端白屏修复（F-11 ~ F-13）
- 用户报"手机打开只看到米色空白页"。用 Playwright + 本机 Edge（channel: msedge）无头复现 `http://localhost:8080/`，抓 pageerror 定位。
- F-11（致命）：`vite.config.js` 把 element-plus 按组件首字母拆 a/b 两个 chunk，组件间双向依赖造成跨 chunk 循环 → `Cannot access 'ge' before initialization` → Vue 不挂载 → 整屏只有 `body{background:#FAF4E9}`。dev 模式不打包所以一直没发现。改为 element-plus 单 chunk（973.6kB）+ echarts 独立 + 其余 vendor。
- F-12：`WelcomeView.vue` 模板用 `assetUrl()` 但只 import 了 `API_ORIGIN` → 修完 F-11 后首屏仍报 `TypeError`。补 import。
- F-13：`assetUrl()` 只在 IS_DESKTOP 时拼后端地址，原生容器（https://localhost）图片 404；`api/index.js` 的 401 跳转也漏了 IS_NATIVE 的 hash 路由。均改为 `IS_DESKTOP || IS_NATIVE`。
- 配套：mobile 构建不再注入 PWA/SW（APK 内 SW 会在覆盖安装后回放旧缓存）；main.js 原生端冷启动清历史 SW；vite.desktop.config.js 适配回调式 base config；vitest `testTimeout: 20000` 消除路由用例假失败；backend `application.yml` 开 gzip（需重打 jar + 重启才生效）。
- 产物：APK 1.0.1（versionCode 2，6.16MB）已覆盖 `backend/uploads/downloads/app-release.apk`；`gradle.properties` 加 `android.overridePathCheck=true`（中文路径）；桌面安装包重打 1.0.1。

## 移动端状态栏重叠 / 平板适配（F-14）
- 现象：白屏修好后，导航压在状态栏下；平板仍是桌面双栏（用户真机截图 1536×1079，容器实测 ~1180 CSS，视口约 1250）。
- 根因1：targetSdk 35 → Android 15 强制 edge-to-edge，WebView 画到状态栏下；之前只做了底部 safe-area。
- 根因2：断点 900/860 太小，平板/折叠屏 CSS 宽度常 900~1300，仍命中桌面布局。
- 修复：`--safe-top/--safe-bottom` 变量 + `.w-nav/.nav` padding-top；`App.vue` 公开页 `.safe-top`；断点 900→1024、860→1024；新增 `(pointer:coarse) and (max-width:1366px)` 触屏平板单栏；单栏时照片墙限宽 560 居中；`capacitor.config.json` 加 `adjustMarginsForEdgeToEdge:"force"`；`styles.xml` 状态栏/窗口底色 #FAF4E9 + windowLightStatusBar。
- 产物：APK 1.0.2（versionCode 3，6.16MB）已覆盖 uploads/downloads；验收：1250 coarse 单栏 / 390 手机紧凑 / 1440 桌面双栏、15 路由 0 报错、vitest 12/12。
