# E-06（P2·前端）演示占位清理：假评价、微信登录/忘记密码占位、搜图装饰动画

> E 批第 6 条（共 8 条）。纯前端改动，可随时穿插执行。总览与公共红线见 `00-索引与执行顺序.md` 及本文末尾。

## 现象与证据

以下均为答辩时"一眼假"的占位/编造内容：

1. **登录页假用户评价**：`AuthView.vue:149-162` 两条静态评价（"林晓 计算机学院·大三"、"周航 机械学院·大二"）为编造文案。WelcomeView 的同类好评已按 F-08 清理，AuthView 是漏网残留，两处口径不一致。
2. **微信登录纯占位**：`AuthView.vue:117` 点击仅弹 `ElMessage.info('演示环境：微信登录暂未接入')`，按钮带"演示"角标。
3. **忘记密码纯占位**：`AuthView.vue:106` 点击弹 `'演示环境：请联系管理员重置密码'`，带"演示"角标。
4. **搜图三步流程动画是装饰性 sleep**：`SearchImageView.vue:49-50` 用 `await sleep(450)/sleep(550)` 人为拉长流程动画，与真实请求并行跑——进度与实际状态无关。
5. **品牌跑马灯自标演示数据**：`WelcomeView.vue:113-117` 已自标"演示数据，非合作背书"（有标注可接受，本条只做口径复核，不强制删）。

## 修复要求

1. **删除假评价**：移除 AuthView 右侧 testi 区块（:149-162 及对应 `.testi` 样式 :304-316、媒体查询 :339），布局不留空洞（右侧区域若因此空旷，与设计稿 01-交付文档/05 口径核对后调整）。
2. **微信登录**：直接删除该按钮及其入口（无接入计划的占位按钮比明确没有更差）。若组员坚持保留，改为不可点击的"即将上线"弱化样式——**二选一，删除优先**。
3. **忘记密码**：删除"演示"角标与 `ElMessage.info` 占位，改为明确文案的提示弹窗（title"找回密码"，content"请联系管理员在后台重置，或带学生证至 XX 处找回"——文案与 README/运行说明口径一致）。若 E-01 已完成，仍保留此提示（后端无重置通道，属既定范围）。
4. **搜图动画去 sleep**：三步流程改为**由真实请求状态驱动**——"上传识别中"= 请求 pending，"匹配比对"= 响应返回，"结果展示"= 渲染完成；总耗时短就让它短，不再人为 sleep。若希望保留过渡美感，只允许 ≤200ms 的 CSS transition，禁止 JS sleep 掩盖真实进度。
5. **跑马灯口径复核**：确认"演示数据，非合作背书"标注仍在显眼位置即可，无需删除。
6. **全局兜底**：完成后 `grep -rn "演示环境\|demo-tag\|testi" frontend/src` 应无功能残留（CSS 类名清干净）；`npm run build` 通过。
