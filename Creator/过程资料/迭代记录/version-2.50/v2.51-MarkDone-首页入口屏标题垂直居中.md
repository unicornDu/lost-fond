## 三、具体改动

**改动文件**：`web-lostfond/frontend/src/views/WelcomeView.vue`（[.slide.link .slide-in，第 673 行](../../../../web-lostfond/frontend/src/views/WelcomeView.vue#L673)）

```css
.slide.link .slide-in {
  /* 02–04 入口屏只有一句标题：垂直居中，避免压在下三分之一 */
  align-content: center;
  padding-bottom: calc(var(--w-head) + 1rem);
  background:
    radial-gradient(80% 62% at 50% 50%,
      hsl(23 26% 12% / .74) 0%, hsl(23 26% 14% / .44) 48%, hsl(23 26% 14% / 0) 78%),
    /* 底部留一层薄暗，压住 02 屏那种浅色桌面，保证页脚反白可读 */
    linear-gradient(180deg, transparent 82%, hsl(23 26% 10% / .46) 100%);
  transition: transform .8s var(--w-expo-out);
}
```

要点：

- **为什么是上下对称内边距**：`.slide-in` 的顶部原有页头避让（`calc(var(--w-head) + 1rem)`），把底部也改成同一值，`align-content: center` 算出的内容盒中心才等于视口中心；若沿用原来的 `clamp(4.5rem, 10vh, 7rem)`，标题会整体上移约 15px。
- **暗池跟着文案走**：只挪文字不挪渐变，标题会落在亮部、失去可读性；径向渐变的锚点由 `50% 94%` 改为 `50% 50%`。
- **页脚补薄暗**：原底部暗池兼顾了页脚，移到中间后，02 屏的浅色桌面会让白色页脚几乎消失；叠一层 `82%` 起、`46%` 深的线性渐变即可，不影响标题区。
- **01 介绍屏不动**：它有标题 + 两行说明 + 页脚统计，是另一套底部构图；本次只改用户指出的三屏。

## 六、注意事项与回退

- 若希望**01 介绍屏也居中**，改基础 `.slide-in` 的 `align-content` 与底部内边距即可，但它的底部说明文字与「向下滚动」提示会与页脚争空间，建议单独调，不要直接复用本规则。

## 七、补记（2026-10-21 20:10）：热力图月份标签被裁切、颜色过浅

| 项 | 内容 |
|---|---|
| 诉求 | 首页「信息总览」热力图顶部的月份（5月–10月）字头被画布上沿切掉，且文字颜色过浅 |
| 复现 | 1920×1080、把中栏放宽到 980px（右栏收起时的宽度）后，2D 画布宽 898px；改造前截图中 5月–10月每个标签的上半截都被切掉，与用户截图一致。常规 640px 卡片（画布 598px）因宽度受限，裁切不明显 |
| 根因 | 2D 顶边距固定为 `pad + 18 = 24px`，而投影缩放 `s = min(aw/bw, ah/bh)` 随画布变宽而增大；标签绘制在网格上方 `0.3` 格处（`py(...) - 3`），画布宽度超过约 1136px 后投影按高度适配，标签 baseline 被顶到 `≈11px`，10px 字号的字头必然为负、被画布裁掉。颜色方面 `MUTED = mix(--cream, --ink, .52)` 只有 52%，浅色主题约为 `rgb(130,130,128)`，对比度偏低 |
| 改法 | `ActivitySkyline.vue`：① `eng.H2` 与 2D 顶边距各 +16px（顶边距增量乘 `1 - e`，只作用于 2D；3D 的 `top` 仍为 `pad`），顶边距增量与高度增量配对，格子尺寸保持不变；② `MUTED` 混合比例 52% → **72%**（亮色约 `rgb(84,84,82)`，暗色约 `rgb(180,179,175)`），3D 月份/星期标签同步加深，暗色主题随 `--ink` 自动适配 |
| 验收 | 898px 宽画布：5月–10月标签完整，字形上方留白约 17px（修复前为负数）；598px 常规画布、438px 窄屏画布同样完整；3D 天际线的月份标签位置不变且颜色加深；暗色主题截图标签清晰。截图实测文字像素：亮色最深 `rgb(89,89,87)`、暗色最亮 `rgb(176,175,171)`（抗锯齿导致与计算值略有偏差）。`npm run build` 通过；vitest **31/31** |
| 代价 | 2D 卡片高度增加 16px（640px 卡片：`sky` 高 382 → 398px），用来换取标签带且不缩小热力格 |
| 回退 | 删除 `H2` 与 `top` 的 `+16`，把 `MUTED` 的 `0.72` 改回 `0.52` 即可 |

**改动文件**：`web-lostfond/frontend/src/components/ActivitySkyline.vue`（`readTheme()`、`layout()`、`draw()` 三处）。

> 说明：用户截图里的横向条纹是热力图卡片的局部裁剪；本次按宽画布复现并修复，常规与窄屏同时回归通过。
