# 校园失物招领平台 · 接口文档 v1.0

> 交付物编号 04（成员B + 成员C）。RESTful，BaseURL = `http://localhost:8080`（前端经 Vite 代理 `/api`、`/uploads`）。
> 统一响应包装：`{ "code": 200, "msg": "success", "data": ... }`；code≠200 为失败（401 未登录 / 403 无权限 / 404 不存在 / 413 图片过大）。
> 鉴权：请求头 `Authorization: Bearer <token>`（登录/注册返回 token）。标注 🔒 的接口必须登录；🛡️ 需管理员。

## 一、认证 M1

| 方法 | 路径 | 说明 | 入参 | 出参 data |
|---|---|---|---|---|
| POST | /api/auth/register | 注册并自动登录 | `{account,password,nickname?}` | `{token, user}` |
| POST | /api/auth/login | 登录 | `{account,password}` | `{token, user}` |
| GET | /api/auth/me | 🔒 当前登录用户 | — | `user` |

`user` = `{id, account, nickname, avatar, role}`。

## 二、启事 M2 / M4

| 方法 | 路径 | 说明 | 入参 | 出参 data |
|---|---|---|---|---|
| GET | /api/items | 列表+筛选+分页 | `type,category,location,keyword,sort(new|hot),page,size` | `PageResult<ItemVO>` |
| GET | /api/items/{id} | 详情（浏览量+1） | — | `ItemVO`（含 images[]） |
| GET | /api/items/my | 🔒 我的发布 | — | `ItemVO[]` |
| POST | /api/items | 🔒 发布（multipart） | 表单 `type,title,category,location,happenTime,description` + `files`(多张图) | `ItemVO`（后端对每张图算 pHash 入库） |
| POST | /api/items/{id}/mark-found | 🔒 失主标记已找回 | — | null |

`ItemVO` = `{id,type,title,category,location,time,status,owner,views,desc,img,images,userId,mine,similarity?}`。
`PageResult` = `{records,total,page,size}`。

## 三、以图搜图 M3（核心）

| 方法 | 路径 | 说明 | 入参 | 出参 data |
|---|---|---|---|---|
| POST | /api/search/image | 上传图片返回 Top-N | multipart `file` | `ItemVO[]`（按 similarity 降序，含 similarity 百分比） |
| GET | /api/search/indexed-count | 已建 pHash 索引的图片数 | — | `{count}` |
| POST | /api/search/reindex | 为漏算 pHash 的图补算 | — | `{reindexed,total}` |

算法：查询图 → JImageHash `PerceptiveHash(64)` → 64 位指纹 → SQL `BIT_COUNT(phash ^ q)` 求汉明距离 → `≤10` 阈值过滤 → 按启事取最小距离升序 Top-6 → 相似度 = `(1 - dist/64)×100`。

## 六、错误码约定
| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数/业务校验失败（msg 为具体提示） |
| 401 | 未登录或令牌失效 |
| 403 | 无权限（非本人/非管理员） |
| 404 | 资源不存在 |
| 413 | 上传超限 |
| 500 | 服务器异常 |
