## 现象与证据

`frontend/package.json` scripts 只有 `dev/build/preview`；src 下 15 个视图、2 个 store、路由守卫、axios 封装全部零自动化（当前口径为 01-交付文档/07"手工功能测试"，课程未强制前端自动化）。

## 修复要求（按性价比裁剪）

1. 引入 `vitest` + `@vue/test-utils`，补 3 类冒烟用例（无需组件渲染全覆盖）：
   - **路由守卫纯逻辑**：未登录访问受限页 → `/auth?redirect=...`；非管理员访问 `/admin/*` → `/home`；已登录访问 `/auth` → `/home`；
   - **user store**：登录态写入/清除 localStorage（`shiguang_user`）、role 解析；
   - **axios 拦截器**：401 响应触发登出与跳转（mock adapter）。
2. package.json 增加 `"test": "vitest run"`；eslint 为**可选项**，不做不强求。
3. 文档同步：01-交付文档/07 前端行方式注明"手工 + vitest 冒烟"；01-交付文档/08 增加对应用例行并更新总数；01-交付文档/10 数字同步。

## 验收标准

```bash
cd frontend && npm run test && npm run build   # 两者均 exit 0
```
