## 1. 设计语言：暖光手账风

**关键词**：温暖 · 纸感 · 贴纸手账 —— 呼应"拾光=拾起+光"，缓解丢东西的焦虑感。

### 1.1 配色规范（CSS 变量，styles/main.css）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--cream` / `--paper` | #FAF4E9 / #FFFDF8 | 页面底色（米色纸）/ 卡片纸白 |
| `--cream-deep` | #F2E7D3 | 次级底/输入底 |
| `--ink` / `--ink-soft` / `--ink-faint` | #33291F / #8C7C68 / #BCAC95 | 三级文字 |
| `--line` | #EFDFC8 | 描边/分隔线 |
| `--orange` / `--orange-deep` | #FF7D2E / #EA5B0C | 主品牌色：CTA、强调、选中 |
| `--orange-soft` / `--honey-soft` | #FFE9D6 / #FFF3CE | 主色浅底、卡片底 |
| `--mint` / `--mint-soft` | #3FAE83 / #DFF4EA | 招领(found)方向色（与寻物 orange 对立） |
| `--sky` / `--sky-soft` | #5B9BD5 / #E3EFF9 | 安全提示底 |
| `--rose` | #EF6F55 | 警示/驳回 |
| `--safe-top` / `--safe-bottom` | `env(safe-area-inset-*)` | 全面屏顶部状态栏/底部手势条让位（F-14） |

**语义约定**：寻物=橙（警示"丢了"），招领=薄荷绿（好消息"捡到"）；状态角标：进行中=主色斜缎带，已结束=灰缎带。

### 1.2 字体与圆角
- 标题 `--font-display`（圆体感）；正文系统无衬线。
- **字体结论（修复 Z-11，2026-10-16）**：不引入任何外部字体资源（原 ZCOOL KuaiLe 外链已移除，与"校园内网/单机部署"口径一致）；标题字体走系统回退栈 `'Yuanti SC','YouYuan','Microsoft YaHei',sans-serif`，断网/内网环境渲染稳定。
- 圆角体系：卡片/弹层 22px（`--radius`）/ 小控件 12px（`--radius-sm`）/ 按钮与标签 999px(胶囊)。
- 阴影：`--shadow-card` 轻投影 + hover `--shadow-lift` 上浮 6px。

### 1.3 组件规格（Element Plus 定制）
- 主按钮：橙渐变胶囊，hover 上浮 2px + 橙投影。
- 卡片 `paper-card`：纸白底 + 1.5px 描边 + Spotlight 鼠标跟随光晕（ItemCard）。
- **渐变搜索栏 `GradientSearchBar`（2026-10-17，Wall 页）**：26px 圆角胶囊卡片 + 无边框内嵌输入 + 左圆形引导钮（悬浮微转贴纸感）+ 右圆形动作钮（橙→蜜黄渐变，有词时点亮微旋）；卡片背后横贯"薄荷→蜜黄→暖橙→绯红"模糊光带，闲置 0.16 透明度、聚焦 0.45、有词 0.6 显影（移植自 Creator/02-过程资料/02-设计prompt/前端/搜索框.md 的 GradientChatInput 视觉，剥离聊天气泡/音效，色板本地化）；地点/排序下拉收进卡片去框线。
- 表单：玻璃质感输入壳（聚焦橙描边 + 光环）；错误=行内红字。
- 状态标签 `el-tag round`：待审核=warning / 通过=success / 驳回=danger。

## 4. 交互与状态规范

- **加载**：表格 v-loading；按钮 `:loading` + 提交守卫防双击。
- **空态**：统一 `el-empty` + 行动按钮（如"发布一条启事"）；以图搜图无结果给算法解释与建议。
- **错误态**：列表/首页失败显示 alert + 重试按钮（区分"没数据"与"后端挂了"）。
- **反馈**：ElMessage 成功/失败 toast；危险操作(删除/下架/封禁)一律 ElMessageBox 二次确认。
- **动效**：卡片 hover 上浮；入场 fade-up 交错；尊重 `prefers-reduced-motion`。
- **移动端 ≤1024px**：导航折叠为汉堡 + 抽屉（含消息/后台入口）；网格单列；触屏平板（`pointer:coarse` 且 ≤1366px）落地页按单栏渲染（F-14）。
- **安全区**：`viewport-fit=cover` + `--safe-top/--safe-bottom`，顶部导航背景延伸进状态栏、内容整体下移；底部手势条同样让位（F-14）。
