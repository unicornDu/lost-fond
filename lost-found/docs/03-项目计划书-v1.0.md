## 6. 周报模板与协作约定
- 周报三段式：本周完成 / 下周计划 / 风险与求助（每周日交成员A汇总）。
- 分支规范（git 就绪后执行）：main 可发布 / dev 集成 / feature-xxx 开发；提交信息 `模块: 做了什么`。
- 文档命名 `编号-名称-版本.md` 置于 docs/，改动者在群内知会。
