# 网站复刻生成指南（Digg 信息流风格 / 拾光失物招领平台）

> 用途：后续要把这套视觉风格真正落到页面时，把本文件第 1 节的 Prompt 直接交给 AI 即可按流程复现。
> 对应实现版本：`参考imgs/风格预览-Digg信息流-v1.html`（单文件、零依赖、三视图可切换；
> 当前内容为 v2：含亮/暗主题切换、简/繁/英语言切换、右栏独立滚动）。
> 风格原型：Digg 2026 重设计（参考截图 `参考imgs/屏幕截图 2026-10-19 164744.png`）。

## 1. 一键生成 Prompt（直接复制使用）

```text
请按以下规格，为「拾光 · 校园失物招领平台」生成一套 Digg 信息流风格页面
（纯 HTML + CSS + JS 单文件预览，或按约定落到 Vue3 组件，见末尾说明）：

【风格定位】现代新闻聚合信息流（参考 Digg 2026 重设计）：纸白底、近黑墨、
   全站克制无彩色，唯一彩色来源是「分类小圆点」；层级全靠字重+灰阶，不靠大字号跳变。

【配色令牌】（全部走 CSS 变量，亮/暗双主题各一套，挂 `html[data-theme]` 切换）
   亮色：--paper:#FAFAF8（全局暖纸白底）；--surface:#FFFFFF（卡片面）；
   --side:#F4F4F1（导航 hover/选中底）；--ink:#141412（主文字近黑）；
   --ink-2:#6F6F68（次级/摘要）；--ink-3:#A3A39B（元信息/占位）；
   --line:#EBEBE7（极浅分隔线）；--btn:#161614（主按钮近黑，文字反白）。
   暗色：--paper:#131312；--surface:#1C1C1A；--side:#262624；--ink:#F2F1EC；
   --ink-2:#A6A69E；--ink-3:#6E6E66；--line:#2A2A27；--btn:#F2F1EC（反白，文字近黑）。
   分类圆点（全站唯一彩色，两主题共用）：证件卡类 #4A6CF7 蓝 / 电子设备 #2FA46A 绿 /
   生活用品 #E8823A 橙 / 书籍资料 #8B5CF6 紫 / 衣物服饰 #E5484D 红 / 其他 #9A9A92 灰。
   业务状态签（淡彩 pill，唯一例外，两主题各一套透明度底色）：
   亮色 寻找中 #FBEEEC/#C2402F、招领中 #E9F5EE/#1E7A4C、已找回 #EFEFEA/灰；
   暗色对应 rgba(色,.16) 底 + 提亮字色。

【字体】Inter / PingFang SC / Microsoft YaHei 无衬线栈；html 15px；
   卡片标题 19px/800、lh1.42、letter-spacing -0.01em，hover 加下划线；
   摘要 13.5px/400/lh1.65 灰；正文详情 14px/lh1.8；元信息 12px 浅灰；
   导航 13.5px/600；面板标题 14px/800。全站 antialiased。

【间距与圆角】卡片间距 26px；卡内 padding 20-22px；栏间距宽（中栏 padding 26px 34px）。
   圆角体系：卡片 18px / 图片 14px / 导航块 12px / 按钮与标签全圆角 pill。
   卡片 1px 极浅边框或无框，hover 才出现轻投影 0 10px 30px rgba(20,20,18,.05)。

【整体布局：三栏】max-width 1240px 居中：
   ① 左导航 232px sticky 全高：品牌字标（近黑方块 logo +「拾光」+ LOST & FOUND 小字）
      + 图标导航（首页/失物墙/招领墙/以图搜图/发布启事/个人中心/通知，
      选中态浅灰圆角块，可带数量 badge）+ 底部近黑 pill「发布启事」CTA + 用户卡。
   ② 中栏单列 Feed：顶部工具条（「最新」下拉 pill + 类型筛选 pill + 右侧
      列表/网格视图切换圆钮）。
   ③ 右栏 300px：**sticky top:0 + height:100vh + overflow-y:auto 独立滚动**——
      主内容上下滚动时右栏固定不动，右栏内容超出视高时只在其自身区域内滚动
      （overscroll-behavior:contain，6px 细滚动条，颜色跟随主题），
      左右两栏与主内容滚动互不影响；左导航同样 sticky 全高可独立滚动。
      内容：近黑「以图搜图」推广卡（白字 + 白色 pill 按钮 + 右下装饰圆）
      + 「拾金不昧榜」面板（序号+头像+名字+本月归还 N 件）
      + 「热门启事」面板（分类点+标签 / 粗体标题 / 浏览量·帮转数，5 条以上以演示滚动）。
   ≤1080px 时收起右栏。

【右上角工具条：仅主题 + 语言两个控件】（top:14px right:18px 的近黑 pill 条，
   不放任何导航/视图切换功能；正式版此两控件并入左导航顶部或设置区）
   ① 亮/暗主题切换：太阳/月亮单按钮互换图标，切换 html[data-theme]，
      配色经 CSS 变量整体翻转；所有换色元素统一
      transition: background-color/color/border-color .3s ease 平滑过渡
      （transform/box-shadow 的 hover 过渡保持 .18s 不被覆盖）；
      选择写入 localStorage（sg-theme），无记录时跟随 prefers-color-scheme。
   ② 语言切换：pill 按钮显示当前语言缩写（简/繁/EN）+ 下拉菜单
      （简体中文/繁體中文/English，选中项 ✓），点击外部收起；
      文案集中在一个 I18N 字典对象（三语言各一份），元素用 data-i18n="key" 标注、
      含 HTML 的用 data-i18n-html，切换时遍历即时替换 textContent；
      JS 渲染的列表（如失物墙网格）数据按语言字段存储、切语言后重渲；
      选择写入 localStorage（sg-lang），同时更新 <html lang>。
   ③ 预览版的视图切换不走工具条：由左导航（首页/失物墙/招领墙）、
      卡片标题（进详情）、返回按钮（回 Feed）驱动，左导航高亮随视图联动。

【启事卡（Feed 主组件，严格按此结构）】
   分类行：彩色小圆点 8px + 分类名 12px/700 灰 + 右侧状态签 pill
   → 标题 19px/800（可点击进详情）
   → 摘要两行截断 13.5px 灰
   → 大图 aspect-ratio 2.35:1、圆角 14px，左下角悬浮「地点 pill」
      （半透明近黑底 rgba(16,16,14,.55) + backdrop-blur + 反白小字）
   → meta 行（顶部分隔线）：发布者头像 24px 圆形 + 昵称 + 时间，
      右侧「收藏 N」「帮转 N」幽灵小按钮（hover 浅灰 pill）。

【页面清单】
1) 首页 = 信息流：上述启事卡纵向流，4-5 张，含寻找中/招领中/已找回三种状态各至少一张。
2) 失物墙 = 网格：repeat(auto-fill,minmax(240px,1fr))，卡 = 1.45:1 图 +
   分类点 + 标题 14.5px/750 + 地点灰字 + 底部头像行与状态签；hover 上浮 2px。
3) 详情页：返回 pill → 白卡（分类行 + 26px/800 大标题 + 完整描述 + 2.1:1 大图
   + 三格事实卡「丢失地点/丢失时间/pHash 命中数」+ 发布者行
   + 操作行：近黑主按钮「我有线索，发起认领」+ 幽灵按钮「私信失主」「收藏」）
   → 下方「认领流程」步骤卡（①发起认领·自动 pHash 比对 ②失主核验 ③线下交接闭环，
   序号圆点 + 连接线，已完成步绿色对勾）。

【交互】过渡统一 0.15-0.18s；按钮 hover 上浮 1px + 轻投影；
   导航 hover/选中浅灰块；卡标题 hover 下划线；列表/网格视图可切换；
   主题切换时全站配色 0.3s 平滑过渡；语言切换即时无刷新；
   右栏独立滚动不随主内容移动；
   预览版可用顶部固定 pill 工具条切换三视图（标注「风格预览·非最终代码」）。

【响应式】≤1080px 收右栏（三栏→两栏）；≤760px 收左导航（单栏，
   工具条下移不遮挡，事实卡改单列）；断点切换不破坏主题与语言状态。

【内容映射（拾光业务）】导航与文案用真实业务词：失物墙/招领墙/以图搜图/发布启事；
   启事内容贴合校园场景（图书馆/三教/操场/食堂等地点）；
   右栏推广卡文案突出 pHash 卖点：「64 位感知哈希指纹，秒级比对，召回率 85.7%」。

【技术约束】单文件零依赖可双击打开；物品图用 CSS 渐变 + emoji 占位；
   图标用内联 SVG（stroke 2px 线性风格）；不写死外部 CDN。
```

## 3. 与现行设计系统 v2 的差异（落地前必读）

| 维度 | 现行 v2（编辑叙事） | 本方案（Digg 信息流） |
|---|---|---|
| 主色 | 翡翠绿 `#0F7A5C` 强调色 | **近黑 `#161614`**，彩色只留给分类点 |
| 首页形态 | 非对称 Hero + 计数 + 特稿卡 | 无 Hero，直接 Feed 流 |
| 导航 | 顶部 NavBar 横排 | 左侧竖排图标导航（三栏骨架） |
| 卡片 | 状态方块签 + 封面缩放 | 分类圆点 + 大圆角图 + meta 行 |
| 圆角 | 中等 | 偏大（卡 18 / 图 14 / pill） |

**待拍板**：是否保留翡翠绿作为品牌色（建议至少留在「以图搜图」推广卡与主 CTA 的
hover 态），还是全面转向近黑单色。两种都可行，前者品牌延续性好，后者更忠实原型。

## 4. Vue 落地要点（确认方向后执行）

1. 令牌并入 `lost-found/frontend/src/styles/main.css` 的 `:root`：
   **沿用「换肤不改名」铁律**——`--cream*/--ink*` 等旧令牌保留名字、只替换色值；
   新增 `--c-doc/--c-elec/...` 分类点令牌与 `--side/--line` 等中性令牌。
2. 三栏骨架是新结构：左导航组件化（可复用现有 NavBar 的登录态/未读数逻辑），
   右栏三个面板做成独立组件；≤1080px 收右栏，移动端左导航改抽屉（复用现有 drawer 逻辑）。
3. 启事卡改动集中在 `ItemCard.vue`：分类点 + 状态淡彩 pill + 2.35:1 封面 + meta 行。
4. 首页 HomeView 去掉 Hero/计数/特稿卡，改为工具条 + Feed（`latestLost/latestFound`
   合并按时间排序）；「为你推荐」可改作右栏第四块面板，逻辑不变。
5. **不要碰的红线**：element-plus 保持单 chunk（F-11）、图标按需注册、
   `.reveal` 动画用独立 `translate` 属性、图片路径走 `assetUrl()`。
6. 主题与语言：主题用 `html[data-theme]` + CSS 变量双套令牌（参考实现见预览版），
   持久化走 localStorage；多语言正式落地建议 vue-i18n（预览版的 I18N 字典可作词条底稿），
   词条 key 结构保持 `cat.* / st.* / nav.*` 扁平命名。右栏/左导航 sticky + 独立 overflow
   滚动直接搬预览版 CSS 即可。
7. 验收：`npm run build` 通过且无 chunk 警告；vitest 12/12；逐页对照本指南第 1 节令牌值；
   亮暗两主题 + 三语言各过一遍主要页面。
