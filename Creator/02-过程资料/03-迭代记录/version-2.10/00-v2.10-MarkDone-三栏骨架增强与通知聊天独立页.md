## 二、逐项实现

### 2.1 R1 右栏可收起 / 展开

**改动文件**：`frontend/src/components/AppShell.vue`、`frontend/src/components/FeedRail.vue`

**结构**：三栏由 `232px | minmax(0,1fr) | 300px` 改为 `232px | minmax(0,1fr) | auto`，第三列放一个宽度可动画的外壳：

```html
<div v-if="showRail" class="rail-col" :class="{ closed: railClosed }">
  <div class="rail-clip"><FeedRail /></div>
  <button class="rail-toggle" :aria-expanded="!railClosed" @click="toggleRail">…</button>
</div>
```

```css
.rail-col { width: 300px; transition: width .42s cubic-bezier(.22,1,.36,1); }
.rail-col.closed { width: 0; }
.rail-clip { width: 100%; height: 100%; overflow: hidden; }
.rail { width: 300px; }          /* 内容宽度不随外壳收缩，避免逐帧重排 */
```

- **交互**：28×64px 竖向药丸把手，`left: -14px` 骑在分界线上；收起时图标旋转 180°（面板开合隐喻）；`title`/`aria-label`/`aria-expanded` 同步。
- **记忆**：`localStorage.shiguang_rail_closed`（`'1'` 收起），挂载时读取，切换时写入；跨页面、刷新后保持。
- **出现范围**：仅 `home / wall / detail` 三个信息流类路由；`≤1080px` 时右栏与把手一并隐藏。
- **踩坑**：裁剪层最初写成固定 `300px`，外壳收到 0 后内容仍溢出屏幕；必须 `width: 100%` 才会被父级宽度裁掉。另 `.rail` 必须显式 `width: 300px`，否则动画期间面板会跟着压缩重排。

### 2.2 R2 内容随右栏宽度自适应

**改动文件**：`AppShell.vue`、`views/HomeView.vue`、`views/WallView.vue`、`views/DetailView.vue`

在 `.content` 上定义三个宽度上限变量，由 `.shell.rail-closed` 切换：

| 变量 | 右栏展开 | 右栏收起 | 作用页 |
|---|---|---|---|
| `--feed-max` | 760px | 980px | 首页信息流 |
| `--wall-max` | 860px | 1180px | 失物/招领墙 |
| `--detail-max` | 760px | 980px | 启事详情 |

- 视图层只引用变量：`.feed { max-width: var(--feed-max, 760px) }`、`.wall { max-width: var(--wall-max, 860px) }`、`.detail-page { max-width: var(--detail-max, 760px) }`。
- 失物墙 `.grid-cards` 使用 `repeat(auto-fill, minmax(240px, 1fr))`，无需额外改列数规则即可自动从 2 列变 3 列。
- **踩坑**：`.shell` 必须绑定 `rail-closed` 类，变量才会切换（首版漏绑，表现为右栏收起了但内容没变宽）。

### 2.3 R3 修复点击左侧导航时的整列抖动

**现象**：点击左侧导航切换页面时，整个左栏（以及整页）横向抖动约 5px。

**定位过程**（CDP 实测）：

| 页面 | `documentElement.clientWidth` | 侧栏 `x` |
|---|---|---|
| `/home` | 1430（有滚动条） | 95 |
| `/wall` | 1430 | 95 |
| `/search-image` | 1440（无滚动条） | 100 |
| `/notifications` | 1440 | 100 |

根因：不同页面内容高度不同 → 竖直滚动条出现/消失 → 视口宽度差 10px → `max-width: 1240px; margin: 0 auto` 的外壳左右各偏移 5px。

**修复**（`styles/main.css` + `AppSidebar.vue`）：

```css
html { scrollbar-gutter: stable; }          /* 始终预留滚动条槽位 */
.side { scrollbar-gutter: stable; }         /* 侧栏自身滚动条也不参与宽度变化 */
.n:focus { outline: none; }                 /* 鼠标点击不再画默认黑框 */
.n:focus-visible { outline: 2px solid var(--ink); outline-offset: 2px; }
```

**结果**：四个页面侧栏 `x` 恒为 95px，抖动消失；键盘 Tab 仍有可见焦点环。

## 五、注意事项（后续改这块必看）

1. **`scrollbar-gutter: stable` 不能删**：一旦移除，长短页面切换会再次出现 5px 横移，看起来就是「侧栏抖一下」。
2. **`.shell` 的 `rail-closed` 类必须绑定**：内容宽度变量挂在 `.shell.rail-closed .content` 上，漏绑会出现「右栏收起了但内容没变宽」。
3. **裁剪层 `.rail-clip` 必须是 `width: 100%`**，且 `.rail` 固定 300px：前者保证折叠后不溢出，后者保证动画期间不重排。
4. **折叠状态只影响桌面**：`≤1080px` 右栏与把手都隐藏，移动端不提供该交互。
5. **通知页只标记当前分栏已读**：不要改成进入页面全标已读，否则侧栏未读角标会瞬间清零，信息架构失真。
6. **`InboxDrawer` 已删除**：通知 / 聊天都是页面，`AppShell` 不再挂抽屉；若以后要恢复抽屉交互，需从 git 历史取回组件并重新接 `@inbox`。
7. **未读角标按类型拆分**：侧栏 `pollUnread` 现在拉 `api.messages()` 后分 `type` 统计（通知=非 dm，聊天=dm），不要再改回 `api.unread()` 的总数，否则两个入口的角标会互相串。
