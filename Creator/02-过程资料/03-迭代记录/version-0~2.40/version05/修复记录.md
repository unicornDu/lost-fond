## 四、过程发现

1. **AdminService 理由校验顺序**：初版把 reason 校验放在写库之后，被单测抓住（"超长理由已写状态才发现 400"）——已改为方法最前先校验；单测同时断言连 selectById 都不发生（Mockito 严格模式连带暴露了未用桩）。
2. **40301 的 HTTP 映射**：40301 不在通用 4xx/5xx 区间，`resp()` 原逻辑会落 500——已补 `40301→403` 专项映射并在 Creator/01-交付文档/04 错误码表登记。
3. **公开主页口径与墙页口径的有意差异**：主页含已找回/已认领（查历史），墙页排除（B-02"仍在流转"）；两者各自复用 HIDDEN/WALL_HIDDEN 常量，未出现第三份手写口径（红线 7）。
4. **axios blob 下载与统一剥壳**：`/admin/export/items.csv` 返回 blob，响应拦截器对 Blob 原样放行（无 code 字段），ToolsView 用独立 `http.get(responseType:'blob')` 下载，不影响 JSON 剥壳逻辑。
5. test_api 原有断言零删除：E 批所有改动都是在原结构上的增量（E-05 仅在原封禁块内插入），`82 → 125` 的差值全部来自新增断言。
