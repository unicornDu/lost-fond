## 二、逐项实现

### 2.1 R1 侧栏滚动条隐藏

**改动文件**：`frontend/src/components/AppSidebar.vue`、`frontend/src/components/FeedRail.vue`

`scrollbar-width: thin` 在 Chrome 里是**常驻可见**的细滚动条，与 Digg 版式里"只有中栏在滚"的观感冲突——右栏那条 6px 灰条会在白卡与推广卡之间竖着划一道。

```css
/* FeedRail.vue .rail */
overflow-y: auto;
scrollbar-width: none;
overscroll-behavior: contain;   /* 保留：到顶/到底后别把滚轮传给整页 */
.rail::-webkit-scrollbar { width: 0; height: 0; }
```

`AppSidebar.vue` 的 `.side` 同步处理，并**去掉了 `scrollbar-gutter: stable`**：滚动条不再占位后，这条留白会变成右侧一条看不见的空隙，和 14px 内边距叠成不对称留白。页面级 `html { scrollbar-gutter: stable }` 仍然保留（防居中壳体横移的既有结论，见 v2.10）。

> 取舍：完全隐藏滚动条会失去"这里还能滚"的视觉提示。右栏四块内容本身有明确的卡片节奏，滚动条反而是噪声，因此按"隐藏即可"执行；要恢复只需删掉 `scrollbar-width: none` 与 `::-webkit-scrollbar` 两行。

### 2.2 R2 位置示意弹层

#### 2.2.1 为什么是「示意图」而不是真实地图

`item.location` 是发布页的 `el-select`（`filterable allow-create`）写入的**纯文本**，`VARCHAR(50)`，库里没有经纬度；地点取值是 `constants/catalog.js` 的 8 个校园地点（第一教学楼 / 图书馆 / 第二食堂 / 操场 / 宿舍楼 / 实验楼 / 校车站 / 体育馆），也允许自建。因此：

- 接高德 / 腾讯地图只能落到"某校区"这一级，看不到楼栋，反而更像编数据；
- 项目已有 `pHash` 这类"自己算出来的真东西"的调性，位置这块也应当**可解释**：图上任何一个点都能追溯到一条地点文本。

于是采用「校园方位示意图 + 文本匹配到楼块」：8 个预设楼块是真地点，图钉落在匹配到的楼块上；对不上的文本落在十字主路交叉口，并标注「自定义地点」。

#### 2.2.3 交互（用原生 CSS/JS 复刻 prompt 的手感，不引 framer-motion）

项目没有 React/framer-motion 依赖，prompt 里的 `motion.div` / `useSpring` 全部用等价的原生做法实现：

| prompt 里的效果 | 本项目实现 |
|---|---|
| 鼠标移动带动 3D 倾斜（`rotateX/rotateY` + spring） | `pointermove` 归一化到 ±1，写 CSS 变量 `--rx/--ry`；`.map-tilt { transform: perspective(1200px) rotateX(var(--rx)) rotateY(var(--ry)) }`，`transition .22s ease-out` |
| 点开从 240×140 展开到 360×280 | 弹层本身带 EP 的进场；地图改「道路生长 + 图钉落下」，小图放大的戏留给了详情页大图 |
| 道路 `pathLength` 生长 | 主路 `pathLength="1"` + `stroke-dasharray: 1`，`stroke-dashoffset` 由 1 → 0，四条路错峰 80/140/200ms |
| 图钉 spring 落下 | `.pin-body { animation: pinDrop .58s cubic-bezier(.34,1.56,.64,1) .45s }`（`translateY(-16px) scale(.55)` → 原位） |
| 绿色发光图钉 | 图钉取**分类色** `catDot(item.category)`，脉冲环同色；沿用"分类圆点是全站唯一彩色来源"，不新增品牌色 |
| `Click to expand` 提示 | 不需要（弹层即展开状态） |

无障碍与降级：`prefers-reduced-motion: reduce` 或 `pointer: coarse`（触屏）时关闭倾斜与全部动画，平面图静态呈现；`.map-svg` 带 `role="img"` 与 `aria-label`。

#### 2.2.4 真实统计与跳转

弹层底部两个真实动作（不编"附近 3 人捡到过"这类数据）：

- **复制地点**：`navigator.clipboard.writeText(item.location)`，失败给 `ElMessage.warning`。
- **在失物墙看该地点 (n)**：`GET /api/items?location=…&type=…&size=1` 取 `total` 作为角标；点击跳 `/wall?type=<item.type>&location=<item.location>`。

> 口径对齐（第一版踩到的坑）：最初只按 `location` 统计，弹层显示「6 条」，点进去的失物墙默认只看寻物、只有 3 条。现在统计与跳转都带上 `item.type`，数字与落地页始终一致，也不会把招领物品带进寻物墙。

#### 2.2.5 两个入口

| 入口 | 位置 | 说明 |
|---|---|---|
| 文字链 | 详情操作行「分享海报」之后，`margin-left:auto` 靠右收尾 | 用户明确要求的位置；`<button class="loc-link">` 带图钉图标 + 箭头，hover 箭头右移 2px |

### 2.3 R3 列表 / 网格视图记忆

**新增**：`frontend/src/composables/useViewMode.js`

```js
export function useViewMode(key, fallback = 'list') {
  let init = MODES.includes(fallback) ? fallback : 'list'
  try {
    const saved = localStorage.getItem(key)
    if (MODES.includes(saved)) init = saved
  } catch (e) { /* 隐私模式：退回默认值 */ }
  const view = ref(init)
  watch(view, (v) => { try { localStorage.setItem(key, v) } catch (e) {} })
  return view
}
```

**接入**：

| 页面 | key | 默认值 |
|---|---|---|
| `HomeView.vue` | `shiguang_home_view` | `list` |
| `WallView.vue` | `shiguang_wall_view` | `grid` |

根因说明：视图是页面里的普通 `ref`，进详情时首页被卸载，返回时重新挂载 → 回到初始值。存 `localStorage`（与 `shiguang_rail_closed` / `shiguang_theme` 同一套做法）后，**"返回"与"刷新"都不丢**；同浏览器下次进来也保持上次选择。

> 只做了"视图"这一项，没有顺手记忆排序 / 类型筛选 / 已加载条数（`shown`）——这三项用户没提，改动会改变筛选语义，留给后续拍板。

## 五、注意事项（后续改这块必看）

1. **平面图坐标与楼名是硬编码的**：改布局要同步改 `campus.js` 的 `blocks` / `label` / `pin` 三处；楼名默认贴楼块**右下角**，图钉在楼块中部——挪动时别让"楼名 + 图钉 + 图钉文案"叠在一起。
2. **图钉文案只在"文本 ≠ 地点名"时显示**（`showPinLabel`）：精确命中时楼块自己有名字，重复挂一遍会显得业余。
3. **统计口径必须与落点一致**：`loadCount()` 与 `goWall()` 都带 `item.type`，改任一处要同步，否则会出现"按钮写 6 条、点进去 3 条"。
4. **`--pin` 是局部变量**，只挂在 `.map-frame` 上（给图钉、命中楼块、图例用）。在同一弹层的头部（如 kicker 圆点）取不到它，别写成 `var(--pin, ...)` 期望继承。
5. **平面图窄屏可读性靠媒体查询放大用户单位**：SVG 按容器宽度缩放，≤560px 时楼名 13 → 21、正门 11 → 17，否则只剩 5–6 个物理像素。
6. **`useViewMode` 的 key 一页一个**，不要共用：首页默认列表、失物墙默认网格，共用会让两页互相改对方的偏好。

### 8.4 这一轮踩到的坑（改这块必看）

1. **innerHTML 与 Vue 的 v-if 兄弟节点互斥**：`paintTiles()` 直接写 `innerHTML` 铺瓦片，如果同一容器里还有 `v-if` 的图钉/提示，Vue 更新时会拿被冲掉的节点当锚点，报 `insertBefore(null)` / `Cannot set properties of null (setting '__vnode')`。**解法**：瓦片放进一个 Vue 不管理的空容器 `.pk-tiles` / `.lc-map`，其余元素常驻、用 class 切透明度。
2. **字段名对不上**：后端 VO 是 `latitude/longitude`，前端第一版写了 `item.lat/item.lng`，于是"接口有坐标、页面说未标注"。改字段时全局搜一遍。
3. **flex 收缩吃掉卡片宽度**：`.lc-stage` 是 flex 子项，默认 `flex-shrink:1`，在 424px 的区块里被挤成 81px。加 `flex: none` 才保住 240/360。
4. **兜底态文字变白**：`.lc.open .lc-bottom h4 { color:#fff }` 是为"压在地图上"准备的，但兜底态没有底图，白字直接消失；所有转白规则都要加 `.has-coord` 前置条件。
5. **`{days}` 占位符**：文案里写了 `{days}` 但 `t()` 只传了 `{n}`，页面上原样显示 `近 {days} 天`；改文案时把 params 一起核对。
