# F-11 / F-12 移动端（含 Web）白屏修复记录 · 2026-10-17

> 现象：手机打开 App / 手机浏览器打开站点，只看到整屏米色（`#FAF4E9`），无任何内容（用户 15:27 截图）。
> 定位方式：本机 Edge（Playwright 无头，Pixel 7 视口）打开 `http://localhost:8080/` 直接复现 → 抓 `pageerror`。

## 根因（两个独立缺陷，必须都修）

1. **F-11 生产构建 TDZ（致命）**：`vite.config.js` 的 `manualChunks` 把 element-plus 按组件名首字母拆成
   `element-plus-a` / `element-plus-b` 两个 chunk。Element Plus 组件之间存在**双向依赖**
   （select→input、date-picker→time-picker/scrollbar…），跨 chunk 形成循环，浏览器报
   `ReferenceError: Cannot access 'ge' before initialization`，入口模块顶层即抛错 → Vue 从未挂载 →
   `<div id="app">` 空，只剩 `index.html` 里那句 `body{background:#FAF4E9}`。
   - `npm run dev` 不打包所以完全正常；`vite build` 才复现（这也是"开发好的、部署白屏"的来源）。
   - 桌面端早在 `vite.desktop.config.js` 用 `manualChunks: undefined` 绕过，**Web/移动端没有同步**。
2. **F-12 落地页缺 import**：`WelcomeView.vue` 模板用了 `assetUrl(...)`，但 `<script setup>` 只 import 了
   `API_ORIGIN`。修掉 F-11 后紧接着报 `TypeError: d.assetUrl is not a function`，首屏（`/`）仍然白屏。

## 修复

| 文件 | 改动 |
|---|---|
| `frontend/vite.config.js` | element-plus 整体归一 chunk（973.56 kB，仍满足"无 >1000kB 单文件"）；echarts 独立、其余进 vendor。保留拆包能力但**不再跨 chunk 切割有环依赖** |
| `frontend/src/views/WelcomeView.vue` | `import { API_ORIGIN, assetUrl } from '../utils/desktop'` |
| `frontend/vite.config.js`（F-12 配套） | `mobile` 模式**不注入 PWA/SW**：APK 里资源本来就在包内，SW 只会在覆盖安装后回放旧缓存 → "更新了还是白屏" |
| `frontend/src/main.js` | 原生端冷启动清一次历史 SW 注册与 Cache Storage（1.0.0 遗留，幂等，Web/PWA 不受影响） |
| `frontend/vite.config.js`（测试稳定性） | `test.testTimeout = 20000`：路由守卫用例首次懒加载 AuthView 时 jsdom 编译整包 Element Plus 约 5.5s，会撞默认 5s 假失败 |

> 现象（用户真机截图）：页面能出来了，但顶部导航压在状态栏下面（时间/电量那一行），
> 而且平板上仍是桌面双栏布局，看起来"没做移动端适配"。

**根因**
1. 工程 `compileSdk/targetSdk = 35`，Android 15 起系统**强制 edge-to-edge**：WebView 画到状态栏底下，
   而前端只处理了底部安全区（`safe-area-inset-bottom`），顶部没有。
2. 落地页/导航栏的移动断点定在 900/860px，平板或折叠屏的 CSS 宽度常到 900~1300px，仍命中桌面双栏。

**修复**

| 位置 | 改动 |
|---|---|
| `styles/main.css` | 新增 `--safe-top / --safe-bottom`（`env(safe-area-inset-*)`，默认 0px）；`.app-main.safe-top` 给无全局导航的公开页让位 |
| `views/WelcomeView.vue` | `.w-nav` 加 `padding-top: var(--safe-top)`（背景延伸进状态栏、内容下移）；断点 900→1024；新增 `(pointer:coarse) and (max-width:1366px)` 触屏平板单栏；≤560px 紧凑档；单栏时照片墙 `width:min(560px,100%)` 居中，避免拍立得错位溢出 |
| `components/NavBar.vue` | `.nav` 同样加 `padding-top`；断点 860→1024（平板收起链接改汉堡） |
| `App.vue` | 公开页（`/auth`、404）主容器加 `safe-top` 类 |
| `capacitor.config.json` | `android.adjustMarginsForEdgeToEdge: "force"`——原生侧直接把 WebView 让出状态栏（CSS `env()` 在 WebView 里不一定拿得到状态栏高度，双保险） |
| `android/res/values/styles.xml` | 状态栏/窗口底色设为米色 `#FAF4E9` + `windowLightStatusBar`，让开安全区后上方不出现异色条 |
