# Z-11（P3·前端/文档）`index.html` 仍外链 `fonts.loli.net` 字体

> Z 批第 11 条（共 11 条）。执行前先读 `Deepseek_后端/00-索引与执行顺序.md`（验收命令口径）。总览与公共红线见 `00-索引与执行顺序.md` 及本文末尾。

## 现象与证据

`frontend/index.html` L8-9：

```html
<link rel="preconnect" href="https://fonts.loli.net" />
<link href="https://fonts.loli.net/css2?family=ZCOOL+KuaiLe&display=swap" rel="stylesheet" />
```

- 04 批 F-07 的验收写的是"`grep -rn 'https?://' src` 仅剩注释/w3.org"——**对 `src/` 成立，但 `index.html` 不在 `src/` 下，因此漏了**（图片已全部本地化，字体还留在外网）。
- 影响：断网时**不破图**，`--font-display: 'ZCOOL KuaiLe', 'Yuanti SC', 'YouYuan', 'Microsoft YaHei', sans-serif` 会回退到系统字体，只是标题字形变化；
- 但与 `01-交付文档/01` §4"**校园内网/单机部署**"的口径不一致，且属"交付物引用了外部资源"这一类答辩问题。

## 修复要求（二选一）

- **A（推荐，成本略高）**：把 `ZCOOL KuaiLe` 字体文件放到 `frontend/public/fonts/`，用 `@font-face` 自托管（注意字体体积；授权需自行核对——该字体在 Google Fonts 上以 OFL 发布，落地前请确认随包分发的许可要求，并在 01-交付文档/05 注明来源与许可）。
- **B（最省事）**：删掉这两行外链，把 `--font-display` 收敛到系统字体栈（如 `'Yuanti SC','YouYuan','Microsoft YaHei',sans-serif`），并在 `01-交付文档/05-UI设计稿与规范` 注明"标题字体使用系统回退，不引外部字体"。

无论哪种，都要在 `01-交付文档/05` 或 `01-交付文档/12` 写一句结论，避免下次又被 grep 出来。

## 验收标准

```bash
grep -rn "https\?://" frontend/index.html frontend/src --include=* 2>/dev/null | grep -v "w3.org\|^\S*:\s*\*\|//.*注释"
# → 无外网资源引用
cd frontend && npm run build     # 成功
# 断网（或 hosts 屏蔽 fonts.loli.net）后 npm run dev，首页标题正常渲染
```
