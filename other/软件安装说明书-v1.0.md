# 拾光 · 校园失物招领平台 —— 软件安装说明书 v1.0

> 面向对象：拿到提交包、需要在本机把系统跑起来的老师或同学。从零开始，约 15 分钟。
> 说明：本文件为 Markdown 底稿，**提交前已/将转换为 Word（.docx）版本**（老师要求 Word 安装说明书放 `other/`），内容一致。
> 更详细的部署细节（打包发布 / 备份恢复 / prod profile）见 `doc/12-部署手册-v1.0.md`。

## 一、环境准备（四个工具）

安装以下工具并确保在 PATH 中（ cmd/终端里能打印版本号即可）：

| 工具 | 版本要求 | 用途 | 自检命令 |
|---|---|---|---|
| JDK | **21** | 编译/运行后端 | `java -version` |
| Maven | 3.9+ | 构建后端 | `mvn -v` |
| MySQL | 8.0+ | 数据存储 | `mysql --version` |
| Node.js | 20+ | 构建/运行前端 | `node -v` |

MySQL 服务须处于**运行状态**：
- Windows：管理员 cmd 执行 `net start MySQL`（服务名以自己机器为准，也可能是 MySQL80）；
- macOS/Linux：`brew services start mysql` 或 `systemctl start mysqld`。

> 没有以上环境？直接用 Windows 桌面版：从 [GitHub Releases](https://github.com/unicornDu/lost-fond/releases) 下载 `Shiguang-Windows-Setup-*.exe` 双击安装（内置 JRE 与 H2 数据库，免装一切），见第六节。

## 二、建库建表（2 分钟）

打开命令行，进入解压出的提交包目录，执行（会提示输入 MySQL root 口令）：

```bash
# 首次初始化（推荐，可重复执行、不清数据）
mysql -u root -p < src/web-lostfond/backend/src/main/resources/db/schema-init.sql
```

> ⚠️ 彻底重置才用 `schema.sql`（每张表前有 DROP TABLE，**执行即清库**，仅开发环境）。

验证：

```bash
mysql -u root -p -e "USE lost_found; SHOW TABLES;"
# 应显示 10 张表（user / item / item_image / claim_record / message / admin_log /
# favorite / delivery / watch_subscription / watch_target）
```

## 三、生成本地配置（1 分钟）

```bash
cd src/web-lostfond/backend
cp application-local.yml.example application-local.yml
# Windows cmd 用：copy application-local.yml.example application-local.yml
```

打开 `application-local.yml`，修改两处 `CHANGE_ME`：

| 字段 | 填什么 |
|---|---|
| `spring.datasource.password` | 本机 MySQL 的 root 口令 |
| `jwt.secret` | 任意 32 位以上随机字符串 |

`seed.admin-password` / `seed.user-password` 已预填 `admin123` / `user123`，不改也能登录。

> 该文件被 `.gitignore` 排除，不会进版本库；**缺失它会启动失败并明确报错**（不会静默回退）。

## 四、启动（两个窗口）

**窗口 1 —— 后端**（⚠️ 必须在 `src/web-lostfond/backend` 目录下启动，图片上传目录 `./uploads` 是相对工作目录的）：

```bash
mvn spring-boot:run
```

日志出现 `Started LostFoundApplication in x.x seconds` 即成功。**首次启动自动播种** 60 条演示启事、120 条图片引用并重算 pHash，无需手工导数据。

**窗口 2 —— 前端**（开发模式，可选）：

```bash
cd src/web-lostfond/frontend
npm install        # 仅第一次
npm run dev        # 浏览器打开 http://localhost:5173
```

**只想开一个进程？** 在 frontend 目录 `npm run build` 生成 `dist/` 后只开后端，直接访问 **http://localhost:8080** —— 后端托管 `dist`，是完整站点。

## 五、验收（1 分钟）

```bash
curl "http://localhost:8080/api/items?page=1&size=1"    # 返回 {"code":200,...} 即接口通
```

浏览器逐项检查：

1. 首页有内容、有图（图来自 `src/web-lostfond/backend/uploads/`）；
2. 登录：管理员 `10000001` / `admin123`（以 application-local.yml 实际配置为准）；普通用户 `20240001`~`20240020` / `user123`；
3. 失物墙有 60 条启事；
4. **以图搜图**：上传 `src/web-lostfond/backend/uploads/_query/q-cup.jpg` → 命中该物品多条启事，相似度接近 100%；
5. 导航栏出现「后台管理」→ 看板 / 审核 / 用户 / 日志 / 运维五个页面可打开。

可选自动化自测（需 Python 3 + `pip install pillow requests`）：

```bash
cd src/web-lostfond/backend
python scripts/test_api.py                        # 141 断言，幂等
python scripts/eval_recall.py --min-recall 0.75   # 召回门禁 85.7%
mvn test                                          # 112 用例
```

## 六、Windows 桌面版（免环境安装）

不想装 JDK/MySQL/Node 的机器，直接用桌面版：

1. 从 [GitHub Releases](https://github.com/unicornDu/lost-fond/releases) 下载 `Shiguang-Windows-Setup-1.1.2.exe`（约 162 MB，SHA256 见 Releases 页 `SHA256SUMS`）；
2. 双击安装（可选安装位置），完成后桌面启动「拾光」；
3. 内置 JRE 21 + H2 文件数据库，**无需任何外部环境**，数据存于 `%APPDATA%\Shiguang`。

功能与 Web 版一致；该版本独立构建于 `src/App-LostFond/`，不影响 Web 版。

## 七、手机 / 公网访问（可选）

后端 `:8080` 同时托管前端，手机只需访问这一个端口：

| 场景 | 打开 | 前提 |
|---|---|---|
| 同一 Wi-Fi | `http://<电脑IPv4>:8080/`（`ipconfig` 查） | 同网、防火墙放行 8080、电脑不休眠 |
| 任意网络 | `https://xxx.trycloudflare.com` | 双击 `src/web-lostfond/scripts/tunnel.bat`（用 `other/Project_operation_software/` 里的 cloudflared），窗口会打印公网地址 |

## 八、常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动报连不上数据库 | `application-local.yml` 未生成/口令不对；或 MySQL 服务没起 |
| 端口 8080 / 5173 被占用 | `netstat -ano \| findstr :8080` 找 PID 结束进程，或改 `application.yml` / `vite.config.js` 端口 |
| 图片全部 404 | 没有在 `src/web-lostfond/backend` 目录下启动（uploads 是相对路径） |
| 搜图结果全 100% 或全空 | pHash 未算：登录管理员 → 后台「运维工具」→ 重建索引（`POST /api/search/reindex`） |
| 401 / 403 | token 过期、账号被封禁或权限不足，重新登录 |
| `npm install` 卡住 | 换镜像：`npm config set registry https://registry.npmmirror.com` |
| 双击 tunnel.bat 一闪而过 | 文件必须保持 GBK(ANSI) + CRLF 编码，勿用 UTF-8 重新保存 |

## 九、演示账号与三条主流程

| 角色 | 学号 | 口令 |
|---|---|---|
| 管理员 | `10000001` | `admin123`（模板默认，以本地配置为准） |
| 演示用户 | `20240001` ~ `20240020` | `user123` |

1. **发布 → 审核 → 可见**：发布新启事显示"待审核"，管理员通过后上墙、才能被搜图命中；
2. **以图搜图**：上传查询图 → 返回 Top-10 及相似度百分比；
3. **认领 → 交付**：认领审核通过自动生成认领证明 PDF，双方在消息中心下载。

安装遇到本说明书未覆盖的问题，查 `doc/12-部署手册-v1.0.md` 与 `doc/运行说明/README.md`。
