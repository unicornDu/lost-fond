# 网站复刻生成指南（dsgninterior.se 风格）

> 用途：下次需要重新生成 / 迭代这套页面时，把本文件直接交给 AI 即可完整复现。
> 对应实现版本：`前端版本01/`（index / projects / archive / office 四页）。
> 原型站点：https://dsgninterior.se/en （北欧极简室内建筑事务所官网）

---

## 1. 一键生成 Prompt（直接复制使用）

```text
请按以下规格生成一个静态站点（纯 HTML + CSS + JS，无需构建工具）：

【风格】北欧极简 editorial，图像主导，UI 克制；无阴影、无圆角、无渐变按钮。
【配色】--color-text:#594037（深棕，主文字/深色层）；--color-bg:#F6F5F4（暖米白背景）；
        --color-accent:#E68762（陶土橘，仅 :focus-visible 描边）。不用纯黑纯白。
【字体】几何无衬线（Jost / Cera Pro），400/500/700 三字重；
        全部字号用 clamp() 流式缩放：
        正文 1.0625rem；卡片标题 1.5rem；中标题 clamp(1.75rem→3rem)；
        大标题 clamp(3rem→4rem)；首屏标题 clamp(3.75rem, 2.61rem+5.68vw, 8.75rem)；
        导航文字统一小写。行高约 1em～1lh，正文 antialiased。
【间距】--gap: clamp(.75rem→1.125rem)；--pad: clamp(1.125rem→2rem)；
        --header-height: clamp(3.5rem→3.875rem)；--footer-height: max(33vh, 25rem)；高度用 100svh。
【缓动】expo-out cubic-bezier(.16,1,.3,1)；expo-in-out cubic-bezier(.9,0,.1,1)；过渡 0.3s。

【页面结构】共 4 页：
1) index.html 首页：100svh 全屏纵向轮播（Swiper 11 CDN，direction:vertical，speed:800，
   parallax:true，mousewheel releaseOnEdges）。首屏为介绍页（大标题+一行描述），
   后续每屏一个项目卡片、整屏为 <a> 可点击。每屏结构：全屏背景图（scale(1.05)，
   data-swiper-parallax="60%"）+ 居中超大反白标题（font-700，text-align:center，
   margin-left:-.05em 视觉补偿）+ 极淡遮罩 hsl(23 24% 28% / .15)。
2) projects.html 项目列表：网格 repeat(auto-fill, minmax(min(26rem,100%), 1fr))，
   gap:--gap，padding:--pad（顶部额外留 header 高度）。卡片为 3:4 竖图 + 下方 1.5rem 标题。
   双色调交互：黑白层（grayscale 滤镜）在下、彩色层在上 opacity:0，
   hover 时彩色层 0.3s 淡入；图片 scale(1.05) + 轻微滚动视差（±5% translateY）。
3) archive.html 档案页：复用同一网格组件，仅数据不同。
4) office.html 工作室页：编辑排版，大标题 font-600 + 窄栏正文(max-width:40em) + 全宽 16:9 配图。

【页头】position:fixed，透明，两列网格：左侧字标（"加粗词 + 常规词"纯文字 logo），
   右侧导航。pointer-events:none 容器 + 子元素 auto。
   深色页（首页）页头反白：body[data-header="light"] 或菜单打开时 color 切为 --color-bg。
   桌面端（≥64rem）：内联小写导航 + 语言切换（当前语言 display:none），hover opacity:.55。
   移动端：menu/close 纯文字按钮（两 span 交叉淡隐+位移），点击展开全屏深棕菜单覆盖层
   （translateY(-100%)→0，0.6s expo-in-out，链接 0.15s 起依次错落淡入）。

【页脚】深棕底、min-height:max(33vh,25rem)、内容靠底（align-content:end）。
   三栏（移动端单栏）：联系邮箱+电话 / 地址（两行 span）/ "滚动探索"提示。
   初始 opacity:0，IntersectionObserver 进入视口 15% 后淡入 + 内容上移（translateY 1.5rem→0）。
   滚动提示为 1px 竖线循环动画：translateY(-18%)→25%，opacity 0→1→0，2.2s 循环。

【内容管理】所有文字与图片集中在一个 content.js 的 SITE_CONTENT 对象中，
   页面 DOM 由 main.js 从该对象渲染；占位图用内联 SVG data-URI 生成器
   （参数：宽高/文字/色调 dark|grey|color）。替换真实内容只改 content.js。

【其他】列表页主标题用 .sr-only 仅供屏幕阅读器；html 底色深棕（overscroll 衔接页脚）；
   -webkit-tap-highlight-color:transparent；响应式：64rem 断点切换导航形态，
   网格与字号全程流式。
```

## 2. 文件结构约定

```
前端版本01/
├── index.html            首页（全屏轮播，依赖 Swiper 11 CDN）
├── projects.html         项目列表（data-page="projects"）
├── archive.html          档案页（data-page="archive"，复用网格）
├── office.html           工作室页（data-page="office"）
└── assets/
    ├── css/main.css      全部样式（设计变量集中在 :root）
    └── js/
        ├── content.js    ★ 占位内容集中管理（唯一需要改的内容文件）
        └── main.js       渲染 + 交互（菜单/轮播/页脚淡入/视差）
```

## 3. 替换真实内容的方式

只改 `assets/js/content.js`：

| 要替换的内容 | 位置 |
|---|---|
| 字标 / 品牌名 | `SITE_CONTENT.brand` |
| 导航项 | `SITE_CONTENT.nav` |
| 首页横幅（标题/链接/图） | `SITE_CONTENT.home.banners` |
| 项目列表 | `SITE_CONTENT.projects.items` |
| 档案列表 | `SITE_CONTENT.archive.items` |
| 工作室页文字与配图 | `SITE_CONTENT.office` |
| 页脚联系方式 | `SITE_CONTENT.footer` |

图片替换：把 `ph(宽, 高, 文字, 色调)` 占位图调用直接换成真实图片 URL 字符串即可。
真实图片接入后建议保留双色调结构（黑白层加 `filter:grayscale(1)` 即可自动生效）。

## 4. 外部依赖

- Swiper 11：`https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.css|.js`（仅首页使用）
- Jost 字体：`https://fonts.googleapis.com/css2?family=Jost:wght@400;500;700`
- 离线部署时可将两者下载到本地 `assets/vendor/` 并改引用路径。

cd 前端版本01
