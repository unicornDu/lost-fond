# 测试计划 v1.0

> 交付物编号 07（牛贺群）。项目：拾光·校园失物招领平台。日期：2026-10-14（2026-10-17 收敛为单 Web 后同步口径）。

## 1. 测试范围

| 模块 | 测试内容 | 类型 |
|---|---|---|
| M1 用户 | 注册/登录/当前用户/封禁/记住我 | 接口+功能 |
| M2 发布 | multipart 发布、图片必填、魔数校验、缩略图、审核流水位 | 接口+功能 |
| M3 以图搜图 | pHash 检索 Top-N、阈值、reindex 鉴权、similar 接口 | 接口+算法 |
| M4 检索 | 类型/分类/地点/关键词/排序/分页/上限 | 接口+功能 |
| M5 认领 | 申请守卫、状态机（通过/拒绝/竞争）、消息通知 | 接口+功能 |
| M6 后台 | 审核/下架/删除（含磁盘清理）/封禁/看板/日志 | 接口+功能 |
| 前端 | 十页面主流程、401 跳转、404、移动导航/安全区、分页 | 功能 + vitest 12 例（Z-05：路由守卫/user store/axios 拦截器，`npm run test`） |
| 非功能 | 搜图延迟、并发、单元测试 | 性能 |

不在本次范围：微信登录（占位）、邮件通知、内容审核 API（可选项未实现）。

## 2. 测试策略

- **接口层**：`backend/scripts/test_api.py` 自动化回归（**141 断言**，幂等，退出码即结果；覆盖 M1-M6 + E 批 + P 批交付）。
- **单元层**：JUnit5 `mvn test`（**99 用例**：PHash/Auth/Claim/Search/FileStorage/Item/Favorite/FileDelivery/Pdf/Admin/Message 等；HashExperimentTest 默认 skip）。
- **前端**：`npm run build` 编译验证 + `npx vitest run`（12 例）+ 浏览器手工走查主流程（含 390/1250/1440 三档视口冒烟）。
- **算法**：`HashExperimentTest` 输出 P/R/F1 与逐变换召回（见报告 11）。
- **缺陷管理**：发现→登记《09-缺陷跟踪表》→修复→回归→关闭。

## 4. 通过准则

- 接口回归 **141/141 PASS** 且脚本退出码 0；连跑多次**八表**行数回基线（幂等）。
- 单元测试 **99 用例、98 执行全绿**（1 个 skip 为 HashExperiment 实验类）、前端 vitest **12/12**；`npm run build` 无错误且构建产物首屏可渲染（防止 F-11 类白屏回归）。
- P0/P1 缺陷全部关闭；P2 可带缺陷发布但须有说明。

## 5. 进度安排（对应分工方案 P4）

W1：测试计划+用例设计 → W2：接口/单元/前端执行+缺陷修复 → W3：回归+实验+测试报告。
